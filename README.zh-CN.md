# PromptShield — 提示词模板集合

🛡️ **PromptShield** 是一套为开发者和独立开发者整理的提示词模板，尝试引导模型给出来源、说明不确定性并遵守拒答边界；它不能保证输出正确。

> **项目边界：** 可复制使用的提示词模板，不是安全扫描器、提示词注入检测器或运行时防护工具，也不能保证模型不产生幻觉。
>
> **维护状态：** 冻结于 v1.6，仅做必要维护；没有功能路线图或快速响应承诺，Issues 按月集中查看。

---

## 🎯 它解决什么问题（为什么存在）

大语言模型即便说错了，也说得信心十足。对任何把 AI 真正塞进产品的人来说，这不是小毛病——这是**法律与品牌风险**：

- **它们会编造。** 虚构的参考文献、假的 DOI、根本不存在的统计数据、凭空捏造的法律条款或医疗建议——而且全程自信满满。
- **它们会越界。** 聊天机器人"诊断病情"、文案编出产品参数、研究者零来源地断言事实。
- **现有的护栏都是给企业用的。** Lakera、Guardrails AI、Microsoft Presidio 这类工具本质都是 API 平台：要注册账号、要鉴权、要搭基础设施、要签月度合同。对于一个只想"让提示词别瞎编"的个人开发者或独立开发者来说，**几乎没有任何轻量方案**。

PromptShield 提供一个轻量的提示词模板起点，尝试提醒模型说明依据、边界和不确定性；提示词本身并不能强制模型遵守，也不能替代人工核验。

## ✨ 它能做什么

你可以把模板粘贴到模型中并提供内容。模板尝试引导模型：

- **优先依据** —— 要求给出来源，或拒绝无依据的断言（研究、引用审计、数据模板）。
- **说明边界** —— 明确不诊断、不提供买卖建议或法律意见等限制。
- **表达不确定性** —— 写明注意事项，区分已提供事实与推断。
- **核验主张** —— 标记需要核实的简历、评价、社媒内容与案例陈述。

每个模板都是一个 **Mega-Prompt**：清晰的 `角色（Role）` + `严格规则（Strict Rules）` + `输出格式（Output Format）` + 你的 `输入（Input）`——正是这种专业结构，让提示词行为稳定可靠。

## 📦 内置内容（20 个模板，10 大类）

- **K-Beauty 成分分析器** —— 化妆品成分拆解，给出保守的 EWG 风格评级
- **高考英语词库生成器** —— 面向中国高考备考的 CEFR B1–B2 词汇表
- **法律问答守卫** —— 只在写明管辖法域 + 双重免责声明后才作答
- **医疗分诊过滤器** —— 症状到科室的路由，绝不诊断
- **必须联网检索的研究员** —— 没有核验过的引用就拒绝回答
- **金融免责守卫** —— 只解释概念，拒绝给出买卖/持有建议
- **代码审查批评家** —— 找 bug 和安全问题，但绝不担保"无 bug"
- **学术引用审计师** —— 标记编造的参考文献，拒绝虚构 DOI
- **客服回复守卫** —— 只依据你的知识库起草客服回复
- **电商文案守卫** —— 严格依据源规格写产品文案
- **简历事实核查器** —— 标记注水 / 编造的简历声称
- **法律合同守卫** —— 标记一边倒的条款，拒绝出具法律意见
- **申请文书守卫** —— 标记编造的履历，拒绝虚构内容
- **数据解读守卫** —— 带注意事项地解释数据，拒绝伪造统计
- **社媒文案守卫** —— 标记未经证实的声称与虚假紧迫感，绝不编造互动数据
- **冷邮件守卫** —— 标记垃圾话术与编造的案例研究
- **商品描述守卫** —— 标记无法证实的规格与虚假好评
- **UX 文案守卫** —— 标记暗黑模式与误导性的界面微文案
- **会议纪要守卫** —— 把原始笔记整理成决策 / 行动项，不编造负责人
- **投资研究守卫** —— 带来源地总结市场信息，不做任何保证

## 🔑 核心特性

- **面向依据与边界** —— 模板要求模型说明来源、不确定性和拒答边界，结果仍需人工核验。
- **真实输入 → 输出示例** —— 购买前就能看到模板到底产出什么。
- **Mega-Prompt 结构** —— 角色 + 严格规则 + 输出格式，在每个模板上都能看到。
- **多模型适配** —— 每个模板都标注了它最适合运行的模型（ChatGPT / Claude / Gemini / Perplexity）。
- **免费示例层** —— 本仓库快照中有 4 个模板标记为 FREE。
- **模板集合** —— 当前仓库快照包含 20 个模板、10 个类别。
- **双语站点** —— 英文 / 中文一键切换。
