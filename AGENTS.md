# PromptShield Agent Guide

PromptShield is a **public** repository containing a frozen v1.6 collection of copy-and-paste prompt templates and a static companion site.

## Project boundaries

- This is not a security scanner, prompt-injection detector, or runtime guardrail.
- Templates may encourage citation, uncertainty statements, and refusals; they cannot enforce model behavior or guarantee accurate outputs.
- The project is frozen at v1.6. Do not add features or promise rapid support; review public Issues periodically.
- No company-owned project, content, customer data, or internal material belongs here.

## Working agreement

1. Read `AI_COLLAB.md` and check `git status` before making changes.
2. Keep edits limited to approved maintenance; preserve unrelated worktree changes.
3. Never commit credentials, subscriber data, or personal information. Subscriber data belongs only in the separate private data repository.
4. Do not push, deploy, change GitHub settings, or contact users without explicit approval.
5. Add a concise entry to `AI_COLLAB.md` when completing repository work.
